PostgreSQL Metrics
Metric	Description
Connections	Number of current client connections to PostgreSQL.
TPS (Transactions Per Second)	Number of transactions processed by PostgreSQL per second.
QPS (Queries Per Second)	Number of queries executed per second.
Cache Hit Ratio	Percentage of data requests served from memory instead of disk.
Locks	Number and status of locks currently held or waiting.
Deadlocks	Number of deadlock events detected by PostgreSQL.
Long Queries	Queries that have been running longer than the defined threshold.
Replication Lag	Amount of delay between the Primary and Replica databases.
WAL Generation	Amount of WAL generated over a specific period.
WAL Archive Status	Status of WAL files being archived successfully.
Checkpoint	Number and duration of checkpoints performed by PostgreSQL.
Database Size	Total disk space consumed by each database.
Table Size	Disk space consumed by individual tables.
Index Size	Disk space consumed by indexes.
Dead Tuples	Number of obsolete row versions waiting to be cleaned by VACUUM.
Autovacuum	Status and activity of PostgreSQL automatic vacuum processes.
Temp Files	Number and size of temporary files created by queries.
I/O	Read/write operations and I/O time generated by PostgreSQL.
Active Sessions	Number of sessions currently executing queries.
Waiting Sessions	Number of sessions waiting for locks or other resources.
Replication Slots	Status and WAL retention information for replication slots.
Connection States	Number of connections in states such as Active, Idle, and Idle in Transaction.
Patroni Metrics
Metric	Description
Primary Status	Indicates whether the current PostgreSQL node is the Primary.
Replica Status	Shows the health and state of PostgreSQL Replica nodes.
Cluster State	Overall health and state of the Patroni cluster.
Leader	Identifies the current Patroni leader node.
Failover	Detects and tracks Primary failover events.
Replication Lag	Measures replication delay between Primary and Replica nodes.
PostgreSQL Running	Indicates whether PostgreSQL is currently running on the node.
Patroni API Status	Indicates whether the Patroni REST API is available.
DCS Status	Shows the health of Patroni communication with the Distributed Configuration Store such as etcd.
Timeline	Current PostgreSQL timeline, useful for detecting failover and recovery events.
PgBouncer Metrics
Metric	Description
Client Connections	Number of clients currently connected to PgBouncer.
Server Connections	Number of connections from PgBouncer to PostgreSQL.
Active Connections	Number of connections currently being used.
Waiting Connections	Number of clients waiting for an available database connection.
Pool Usage	Current utilization of the configured connection pool.
Pool Size	Number of server connections allocated to each pool.
Max Client Connections	Number of connected clients compared with the configured maximum.
Connection Errors	Number of failed client or server connection attempts.
Query Wait Time	Time clients spend waiting for an available connection from the pool.
etcd Metrics
Metric	Description
Leader	Identifies the current etcd cluster leader.
Member Health	Health status of each etcd cluster member.
Leader Changes	Number of times the etcd cluster leader has changed.
DB Size	Total size of the etcd backend database.
DB Size in Use	Amount of the etcd database currently being used.
Raft Commit	Number and status of committed Raft operations.
Raft Proposals	Number of proposals submitted to the Raft consensus system.
Request Latency	Time required for etcd to process client requests.
Active Clients	Number of active clients connected to etcd.
Failed Requests	Number of failed etcd requests.
Disk Sync Duration	Time required to synchronize etcd data to disk.
Network Traffic	Network traffic exchanged between etcd cluster members.
Linux / OS Metrics
Metric	Description
CPU Usage	Percentage of CPU resources currently being used.
Load Average	Average number of processes waiting for CPU or system resources over 1, 5, and 15 minutes.
Memory Usage	Percentage and amount of system RAM currently in use.
Swap Usage	Amount of swap memory currently being used.
Disk Usage	Percentage of filesystem space currently in use.
Disk IOPS	Number of disk read/write operations performed per second.
Disk Throughput	Amount of data read from or written to disk per second.
Disk Latency	Time required for disk I/O operations to complete.
Network Traffic	Amount of inbound and outbound network traffic.
Network Errors	Number of network interface errors and dropped packets.
Open Files	Number of file descriptors currently opened by the system/processes.
Processes	Number of running and active processes on the server.
System Uptime	Amount of time the operating system has been running since the last reboot.
HAProxy Metrics
Metric	Description
Frontend Connections	Number of client connections received by HAProxy.
Backend Connections	Number of connections established between HAProxy and backend servers.
Active Sessions	Number of currently active HAProxy sessions.
Backend Health	Health status of backend PostgreSQL or service nodes.
Backend Down	Number of backend servers currently unavailable.
Response Time	Time required for backend servers to respond to requests.
Connection Errors	Number of failed connections between clients, HAProxy, and backends.
Queue Size	Number of requests waiting in the HAProxy queue.
Traffic	Amount of network traffic processed by HAProxy.
Keepalived Metrics
Metric	Description
VRRP State	Current VRRP state of the node, such as MASTER or BACKUP.
VIP Status	Indicates whether the Virtual IP is currently assigned to the node.
State Changes	Number of MASTER/BACKUP state transitions.
VRRP Packets	Number and status of VRRP packets exchanged between nodes.
Priority	VRRP priority used to determine which node should become MASTER.
Failover Events	Number of Virtual IP failover events.
pgBackRest Metrics
Metric	Description
Last Backup Status	Indicates whether the latest backup completed successfully.
Last Full Backup	Timestamp of the most recent full backup.
Last Differential Backup	Timestamp of the most recent differential backup.
Last Incremental Backup	Timestamp of the most recent incremental backup.
Backup Size	Size of the generated backup.
Backup Duration	Total time required to complete the backup.
WAL Archive Status	Indicates whether WAL files are being archived successfully.
WAL Archive Lag	Time or amount of WAL waiting to be archived.
Repository Size	Amount of storage currently consumed by the backup repository.
Backup Retention	Number of backups retained according to the configured retention policy.
